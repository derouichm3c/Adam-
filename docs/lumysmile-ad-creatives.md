## 📌 Notes

- **3 angles distincts** couverts : écolo, esthétique-problème, esthétique-preuve.
- La vidéo #4 est un clip fournisseur (générique) — à remplacer dès que possible
  par du vrai contenu client / UGC, qui convertit mieux.
- Statistiques marketing (ex. « 80% », « 2,000+ ») : à remplacer par tes vrais
  chiffres dès les premières ventes/avis pour rester 100 % conforme.
- Idée d'amélioration future (quand crédits rechargés) : versions verticales 9:16
  pour Reels/Stories (CPM plus bas).
